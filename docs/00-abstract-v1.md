# Thesis abstract, version 1 (as shared on 2026-10-27)

Cloud computing has become the backbone of modern digital infrastructure, yet its shared, distributed nature exposes it to increasingly sophisticated security breaches, including DDoS attacks, brute-force intrusions, botnets, and infiltration attempts. Existing machine learning-based intrusion detection systems achieve high accuracy on individual benchmark datasets but suffer from two critical limitations: they generalize poorly to unseen network environments, and their black-box nature prevents security analysts from trusting and acting upon their decisions. This thesis proposes an explainable machine intelligence framework for detection and mitigation of security breaches in cloud environments. The framework employs a hybrid ensemble architectures based on gradient-boosted decision trees with a deep neural network, trained on the available datasets that are independently validated and demonstrated using cross-dataset generalization. SHapley Additive exPlanations (SHAP) are integrated to provide per-alert interpretability, enabling analysts to identify the network features driving each detection. A rule-driven mitigation module translates high-confidence detections into automated response actions such as source blocking and alert escalation. Experimental results are evaluated using precision metrics with detection latency and computing complexity. The proposed framework aims to bridge the gap between detection accuracy and operational trustworthiness, offering a practical, interpretable, and generalizable defense mechanism for cloud service providers.
